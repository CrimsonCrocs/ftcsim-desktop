FTC Simulator AdvantageScope bridge

Run: bun ftc-advantagescope-bridge.js
Paste the private bridge URL into the simulator's Telemetry > Analysis > AdvantageScope panel.
In AdvantageScope choose File > Connect to Simulator > FTC Dashboard.
Keep the terminal open. Ctrl+C stops the bridge.

Requires Bun (https://bun.sh). The bridge listens only on 127.0.0.1:8000.
