# DECODE field artwork

These textures restore the printed artwork that STEP geometry cannot carry.

- `goal-tag-blue-20.png`, `goal-tag-red-24.png`, and `obelisk-tag-21.png` through
  `obelisk-tag-23.png` are rasterized from FIRST's official
  `DECODE_AprilTagArtwork.pdf` production-art download.
- `ftc-logo-white.png` is rendered from FIRST's official one-color reverse
  vertical FIRST Tech Challenge logo EPS.

The simulator uses these only in the `decode-2025-2026` field preset. The blank
CAD plates remain the physical surfaces; the artwork is a non-colliding visual
layer placed a few millimetres in front of them.
