# Brand assets

- `ftcsim.svg` is the supplied FTC Simulator mark.
- `crimson-crocs-collection.png` is the user-supplied Crimson Crocs Collection
  banner, copied without image changes from `crocs col-real1.png` (2172 × 497).
  The welcome screen uses it for the requested software-collection attribution;
  rounded corners are applied with CSS.
- `google-g.png` is Google’s official multicolor G asset from the
  [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines).
  It is used only inside the Google authentication control and must not be
  recolored or distorted.
